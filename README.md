# apv-frontend
Fontend de la clínica veterinaria del proyecto Full Stack JS

# Inicio del servidor de desarrollo
Para iniciar el servidor de desarrollo, teclea en la consola:
    npm run dev

# Despliegue en servidor
En la carpeta config crea un fichero llamado config.js, copia el contenido de 
configDemo.js en él y sustituye los valores por los de tu servidor
¡Edición!
En la raíz del proyecto crea un fichero llamado .env y copia todo el contenido de 
.envDemo, cambiando los valores por los correspondientes a tu servidor
Prueba: 
En Registrar.jsx dejo la variable del config, y en ConfirmarCuenta.jsx la variable de entorno, para comprobar si complia bien el proyecto y coge correctamente el config
